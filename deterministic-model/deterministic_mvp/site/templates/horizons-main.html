What must be specified before longer horizons can be compared?

A horizon selector is not enough. Targets, timing and portfolio rules must agree.

  1. Define the return targets

    Specify exact entry and exit prices for one-, three- and six-month predictions, along with a common feasible sample.

  2. Respect target completion

    A six-month return cannot enter training until all six months have finished. Tuning folds need the same rule.

  3. Specify the trading strategy

    Decide whether portfolios hold for the full horizon or rebalance monthly, how overlapping holdings work, and how views and covariance use matching units.

  4. Evaluate overlapping outcomes honestly

    Longer targets can overlap. Error summaries and uncertainty checks must account for that dependence.

  5. Record a separate specification

    The locked corrected reference is a one-month model. A new horizon study needs its own documented rules before running or inspecting its results.
