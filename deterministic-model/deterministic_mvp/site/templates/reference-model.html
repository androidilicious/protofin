What did we fix?

The original model once predicted a monthly SPY return of about +589%. A policy input had very little observed history and barely changed in training, so a new value was magnified during scaling. We now limit unusual inputs using earlier training data and switch off policy inputs until they have enough history and variation. The updated model has no predictions beyond ±20% in this development sample. The old 23.99% portfolio return remains below for comparison; it is not the updated result.

How much policy history is enough to use an input?

We require enough original observations and enough variation before using a policy input. Filled-in or carried-forward values do not create new observations. If an input fails these checks, it has no effect on the forecast.

The exact rules are 12 distinct source observations, three distinct values when rounded to one-basis-point bins, and a standard deviation of at least one basis point before and after filling missing values and limiting extreme inputs. One basis point is 0.01 percentage points. These fixed safeguards are repeated in every training and tuning window; they are not proof that an input helps predict returns.

The rules are locked. Final testing comes next.

We chose these rules after reviewing the development data, so the results above are not a final test. This version has not been tested on 2023 onward. Before using those years for a final test, the team needs to confirm that they have not already influenced the model’s design. The data also include later revisions, and some release dates are assumed; fixing the predictions does not remove those limits.
