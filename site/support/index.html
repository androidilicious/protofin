Decision support · evidence plugins on one gate

How much should a manager believe each piece of evidence this month?

Every plugin answers the same masked month. The harness calibrates the answer, measures how often that plugin has been right lately (its trust, Ω), blends it with Black-Litterman and shows what following it would have done, next to doing nothing and a placebo. The allocation is the consequence, not the advice.

Registry

A plugin is a folder with a manifest and a plugin.py that returns typed answers from saved runs. The harness never calls a model; it scores what was saved. See decision_support/README.md.
