The dashboard asks the committee once and trusts the confidence word it reports. Here the same committee was asked five times on identical data with a little randomness (temperature 0.2), for every month since January 2004. If its answers scatter, that scatter is added to its uncertainty, so a committee that contradicts itself gets less say. Method by Farnoosh Memari (docs/EMPIRICAL_UNCERTAINTY.md): Ω = c · τΣ + s². All answers were recorded once on a laptop and saved; this page only replays them, so no model is called and there is no API behind it.
