ask the committee several times · use its disagreement as uncertainty
Dashboard Jev

The dashboard asks the committee once and trusts the confidence word it reports. Here the same committee is asked several times on identical data with a little randomness. If its answers scatter, that scatter is added to its uncertainty, so a committee that contradicts itself gets less say. Method by Farnoosh Memari (docs/EMPIRICAL_UNCERTAINTY.md): Ω = c · τΣ + s². Each run uses live gpt-4o calls: 3 per ask. Limit: 10 runs per visitor per day.
