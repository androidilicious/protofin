# GO / NO-GO for opening the protected historical window — 2026-10-28

**Decision: NO-GO.** The 2023-01..2026-08 window stays sealed, so no protected historical results exist.

The primary comparison has three approaches:

| Primary approach | System | State |
|---|---|---|
| Deterministic Quantitative Model | AP1 | Implemented, reproduced, development diagnostics |
| Agentic Workflow, represented by JEV | AP2B | Implemented (native replay), reproduced, development diagnostics |
| Agentic Causal RAG | AP3 | Built and tested without a model; **awaiting validation, results unavailable** |

The Agent Committee (AP2A) is a within-approach variant of the Agentic Workflow. Its code, saved outputs, reproduction tests and development diagnostics are preserved, and it is compared only with JEV. A Committee + JEV combination is proposed and not built. Signal ablations, market-regime experiments and Standard RAG vs Causal RAG are secondary experiments, all proposed.

The primary contrasts are AP2B−AP1, AP3−AP1 and AP3−AP2B in net CER (certainty-equivalent return, δ = 2.5), Holm-corrected as one family. Only AP2B−AP1 exists on development months. The primary research timeline begins with the February 2015 macro-data training period.

Machine-readable record: `native_backtest/out/gate_record_v2_2026-10-28.json`, which supersedes v1. The evaluator's lock refuses to score protected months unless a signed GO record exists.

## What must happen before GO

1. Approve AP3 inference (provider, $ cap), add the credential as an environment secret, and allow the provider host (see `AP3_MODEL_HOSTING_AND_COST.md`).
2. Provide data access for the AP3 corpus and mediators: allow `www.federalreserve.gov` and `fred.stlouisfed.org` for this environment, or supply pinned copies. Fed funds futures need a Bloomberg export, or approval to drop that one mediator.
3. Decide the TLT gate 5 result (required for the primary Agentic Workflow, JEV): accept with the documented C2 deviation, or obtain pre-2018 raw TLT prices and re-run. Records and results are in `TLT_DISTRIBUTION_CHECK_2026-10-28.md`.
4. Run AP3's smoke run, fixtures, development replay, human audit and calibration gates.
5. Review and sign the contamination register and hindsight audit (draft in `CONTAMINATION_REGISTER_AND_HINDSIGHT_AUDIT_v1.md`, including H2: the rationale for JEV as the primary Agentic Workflow system); review the October 23 deck.
