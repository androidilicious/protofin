    Prompt & flow
    How it runs Exact prompt Raw reply

    Two independent views, then a decision. The economist and the risk manager are separate model calls with different personas and the same data; neither sees the other. For saved gpt-4o runs the two calls are made concurrently. For the in-browser model they are still independent but execute one after the other, because one GPU generates one reply at a time. The CIO then receives both replies verbatim and sets the numbers that feed Black-Litterman.

    Signals are gathered first (four data sources, deterministic). The model call is the only non-deterministic step, run at temperature 0. Everything after the reply is closed-form mathematics.

    Three user messages, one per persona; there is no separate system prompt for the hosted model (the in-browser model gets a short format-only system line). The CIO prompt is shown with the two views inserted, exactly as sent.
